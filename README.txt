UPLOAD:
1. Extract this ZIP on your phone/computer.
2. In your GitHub ZINTRIQ repository, upload index.html and the css/ and js/ folders, preserving the folder structure.
3. If GitHub asks to replace index.html or existing CSS files, replace them with these new complete frontend versions.
4. Commit changes.
5. GitHub Pages should serve the frontend from the repository root if Pages is configured for the main branch/root.

IMPORTANT BACKEND NOTE:
This is a complete responsive frontend foundation with working navigation, theme toggle, local draft storage, account placeholders, calendar view, and AI/inbox/analytics UI.
The exact backend API details were not available when this package was built. Therefore live OAuth, real publishing, AI generation, inbox sync and analytics are NOT connected yet. js/api.js is a safe API adapter template. Set the backend base URL there only after confirming your actual backend routes. Never put secret keys or OAuth client secrets in frontend files.
